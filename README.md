# EXIT · Blockchain Research & Monitoring

**Blockchain research. Grounded in evidence.**

EXIT builds research infrastructure for understanding what happened, who could act and what changed — with inspectable sources, time bounds and limitations. First specialization: control and change analysis.

- **For people:** recorded public investigations and a guided research interface.
- **For builders:** a versioned API for supported structured questions.
- **For organizations:** permission-scoped reports; organizational workspaces are planned.

**Current:** public case notes, an offline edition and a restricted research alpha. A quota-limited, 30-day free API is being prepared; it is not open yet. No wallet, blockchain token or payment will be required for that campaign; no automatic paid conversion.

The Owner selected **Jupiter Studio / Meteora Dynamic Bonding Curve on Solana** after free API access opens. The month need not finish first. No official mint address or launch is announced. The optional paid API Pass is a separate later integration. Creation and signing remain the Owner’s actions.

After the finite first service: inspectable planning, a temporal research graph, selective network coverage, measured monitoring and organizational workflows. Each increment must improve quality, completion, speed or cost; growth does not erase evidence limits.
